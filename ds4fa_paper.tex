\begin{abstract}
The emergence of massive Mixture-of-Experts (MoE) models, such as DeepSeek V4 Flash (284B parameters), presents significant challenges for local inference on consumer-grade hardware. While Apple Silicon has traditionally dominated this space due to its unified memory architecture, the arrival of AMD's Strix Halo (Ryzen AI Max) platform introduces a comparable 256-bit LPDDR5X unified memory pool. This paper introduces \texttt{ds4fa} (ds4 for AMD), a minimalist, high-performance C inference engine ported from Metal to ROCm/HIP. We detail several hardware-specific optimizations, including APU Zero-Copy memory mapping via \texttt{hipHostMalloc}, hardware-accelerated matrix multiplications using Wave Matrix Multiply-Accumulate (WMMA) intrinsics, and a hybrid iGPU+NPU framework for native Multi-Token Prediction (MTP) speculative decoding. Our results demonstrate that with appropriate low-level kernel tuning, AMD APUs can achieve inference performance parity with high-end unified memory workstations.
\end{abstract}

\section{Introduction}
DeepSeek V4 Flash represents a paradigm shift in open-weights MoE models, offering 284B parameters with a 1-million-token context window. However, its memory requirements (approximating 80GB for 2-bit quantized routed experts) exceed the capacity of standard discrete GPUs. The original \texttt{ds4} engine optimized this model for Apple Silicon using Metal. 

In this work, we present the architecture of \texttt{ds4fa}, a port targeting AMD's ROCm ecosystem. We specifically focus on the Strix Halo architecture, which integrates 40 RDNA 3.5 Compute Units (CUs) and an XDNA 2 NPU into a single silicon die sharing up to 128GB of system RAM.

\section{System Architecture and Memory Model}
\subsection{APU Zero-Copy Integration}
The most critical performance factor on an APU is the elimination of PCIe bus transfers. In \texttt{ds4fa}, we utilize the \texttt{hipHostMallocMapped} flag to allocate transient buffers and the KV cache. This establishes a Shared Virtual Addressing (SVA) space where the CPU and iGPU access the same physical memory pages. Unlike standard managed memory, this approach avoids OS-level page migration heuristics, yielding a deterministic zero-copy path equivalent to Apple's \texttt{MTLResourceStorageModeShared}.

\subsection{ROCm 7.3 SOMA Memory Management}
To handle the dynamic nature of LLM generation (e.g., top-k expert selection), we leverage the ROCm 7.3 Stream Ordered Memory Allocator (SOMA). By using \texttt{hipMallocAsync} and \texttt{hipFreeAsync}, memory reallocation is enqueued on the GPU command stream, preventing CPU synchronization stalls during the inference loop.

\section{Kernel Optimizations}
\subsection{WMMA Matrix Acceleration}
Strix Halo's RDNA 3.5 architecture includes dedicated AI accelerators. We rewritten the core GEMM kernels to utilize raw WMMA intrinsics:
\begin{lstlisting}[language=C++]
__builtin_amdgcn_wmma_f32_16x16x16_f16_w32(
    acc, input_a, input_b, acc);
\end{lstlisting}
This allows the engine to perform 16x16x16 matrix-multiply-accumulate operations in a single wavefront dispatch, significantly increasing the throughput of the model's massive FFN and Attention projections.

\subsection{Single-Cycle 2-bit Dequantization}
DeepSeek V4 utilizes \texttt{IQ2\_XXS} quantization. In \texttt{ds4fa}, we utilize AMD-specific bitfield extraction (\texttt{ubfe}) to decode 2-bit indices directly into registers.
\begin{lstlisting}[language=C++]
const uint32_t val = __builtin_amdgcn_ubfe(
    aux32_s, bit_offset, 2);
\end{lstlisting}
This replaces traditional bitwise shifts and masks, reducing the decoding latency for the 256 experts to a near-negligible cost.

\section{Hybrid iGPU + NPU Speculative Decoding}
DeepSeek V4 features native Multi-Token Prediction (MTP) modules. \texttt{ds4fa} introduces a hybrid execution model where the sequential drafting of MTP tokens is offloaded to the XDNA 2 NPU via the Xilinx Runtime (XRT) API. 
The NPU generates $k$ future tokens into the unified zero-copy buffer, which the 40 CU iGPU then verifies in a single parallel batch. This division of labor exploits the NPU's power efficiency for sequential tasks and the iGPU's massive bandwidth for parallel verification.

\section{Conclusion}
\texttt{ds4fa} proves that high-parameter MoE inference is highly viable on AMD unified memory APUs. By combining ROCm 7.3's asynchronous memory management with RDNA 3.5's matrix cores and a hybrid NPU handoff, we achieve a hardware-native inference loop that maximizes the potential of the Strix Halo platform.
